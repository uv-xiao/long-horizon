# Start Execution

Read `.agents/templates/long-horizon/execution-brief.md` and the current
operation-mode decision.

Runtime-owned mode uses template process/transition/report commands. Native
agent mode verifies native hooks/loop features and gives the generated brief to
that agent without duplicating the loop. Hybrid mode does only the missing
runtime parts.
